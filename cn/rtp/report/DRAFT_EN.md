# CN report guide

The earlier prose draft mixed planned hardware work with saved simulations.
This public copy uses the retained [hardware table](hw_tables.md) and raw
`../results/T2` through `T9` snapshots as the measurement source.

CN-T8 hardware adaptation is pending. CN-T7 uses synthetic service on hardware.
Packet loss, frame loss, on-time ratio, inference latency and AoI have different
denominators/endpoints. Read the table's validity and thermal notes.
`sim_tables.md` is a retained simulated summary, not hardware evidence.
The local staging task did not rerun hardware or ns-3.

Original draft input commit and hash are in docs/provenance/files.csv at the
repository root. Its raw authoring narrative is not a release claim.
