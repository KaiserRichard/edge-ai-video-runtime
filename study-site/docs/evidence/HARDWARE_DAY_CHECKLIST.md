## Part 1 — OS Day (Raspberry Pi 5 + STM32 Nucleo-F446RE + Logic Analyzer)

### 1.1 Wiring & Logic-Analyzer Channels (`os/stm32/firmware/README.md:148-167`, `os/docs/ENVIRONMENT_AND_HARDWARE.md:60,145-152`)
3.3 V logic (no level shifter), common GND; keep ST-LINK USB plugged into Pi for 8 MHz HSE MCO (`os/stm32/firmware/README.md:53,64-67`); no Pi UART jumpers on PA2/PA3 (`:159`).

| Signal | Raspberry Pi 5 | Nucleo-F446RE | Logic Analyzer / Purpose |
|---|---|---|---|
| UART TX→RX | Pin 8 (GPIO14, UART0 TX) | PA10 (Arduino D2, USART1 RX) | Pi→MCU 921600 8N1 (`:152`) |
| UART RX←TX | Pin 10 (GPIO15, UART0 RX) | PA9 (Arduino D8, USART1 TX) | MCU→Pi 921600 8N1 (`:153`) |
| Ground | Pin 6 (GND) | GND | Common reference (`:154`) |
| Sync pulse | Pin 11 (GPIO17) | PA0 (Arduino A0, TIM2_CH1 AF1) | Rising-edge sync (`:155`) |
| Fresh / State | — | PA5 (D13/LD2), PB5 (D4) | LA Ch0 = PA5, Ch1 = PB5 (`:156-157`) |
| ST-LINK USB | Pi USB host | CN1 Mini-B USB | Power, SWD flash/reset, optional VCP (`:158-159`) |

**PA5 / PB5 truth table** (`os/stm32/firmware/README.md:161-166`): `INIT` = `0/0`, `FRESH` = `1/1`, `HOLD` = `0/1`, `FAILSAFE`/fatal = `0/0`.
