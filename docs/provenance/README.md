# Public provenance

`files.csv` maps original source paths and hashes to reviewed public derivatives.
Git source paths are relative to the repository named by `source`; commit hashes
are in NOTICE. Hardware files from CN-wt-HWAN2 and the coursework additions are
unversioned snapshots, not asserted to be in those Git commits.
`tree-sha256.csv` records public file hashes except self-referential manifests.
Private source locations and audit inventories are kept outside this repository.
The telemetry patch is integrated once; base and patch inputs remain separately
identified. Claude/Codex assistance is disclosed in ../AI_ASSISTANCE.md.
